Es un servidor Survival con una experiencia completamente renovada, donde las posibilidades son enormes y el único límite es tu imaginación.

Explora un mundo transformado con físicas avanzadas, modificaciones a la experiencia Vanilla, nuevos sistemas y enemigos con inteligencia artificial, creando una aventura mucho más dinámica, desafiante e inmersiva.

Construye, explora, sobrevive, experimenta y descubre todo lo que el mundo de CYTOONS tiene preparado para ti.


**📦 INSTALACIÓN**
1️⃣ Instala un Launcher compatible
Recomendamos utilizar **Modrinth** App o **Prism Launcher**.

2️⃣ Importa el Modpack
Descarga el archivo **.ZIP** de CYTOONS e impórtalo directamente desde tu launcher.

3️⃣ ¡Conéctate y juega!
Inicia el modpack, entra a nuestro servidor utilizando nuestra IP y comienza tu aventura.
⚠️ Importante: Asegúrate de utilizar **JAVA 21**
